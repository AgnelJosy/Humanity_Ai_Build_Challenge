# Approach and trade-offs

The Class Quality Analyzer evaluates class transcripts against five rubric tiers: Excellent, Good, Average, Weak, and Known Quality Issues. It removes WebVTT timestamps and cue markers, then sends cleaned speech and rubric instructions to the selected language model. Gemini uses the Interactions REST API, while OpenAI uses its chat SDK. The application parses model JSON, validates categories and checklist values, constrains scores to category ranges, and displays a concise summary, evidence, strengths, improvement areas, and tutor feedback. The interface supports uploads, pasted transcripts, connection testing, and downloadable JSON reports for straightforward local review.

A key success is grounding judgments in transcript evidence. The prompt requires short verbatim quotes and prohibits unsupported claims. Since transcripts do not show video, camera and background criteria remain unclear unless someone explicitly mentions them. Errors are logged and shown in the interface, and API keys are entered as secrets rather than embedded in source code.

For speed, the system makes one synchronous model request, caps transcript length, and avoids a database or multi-agent workflow. This keeps setup lightweight but lengthy transcripts may be truncated and evaluations may omit context. Provider outages, invalid keys, rate limits, quotas, or network problems can interrupt analysis. Speech recognition may mishear names or statements, and language models can produce inaccurate classifications despite validation. The application cannot inspect video, independently verify identities, or measure sound quality; it assesses supplied text only. Human review is necessary before sharing feedback or making consequential decisions. Deployments need maintained Python, protected secrets, access controls, and retention policies. Transcripts go to an external provider, so users need permission to share them and must follow privacy rules. Gemini storage is disabled in requests, but provider-side processing policies still apply. Logs may contain diagnostic details and require protection. API access may incur fees and model availability can change.
